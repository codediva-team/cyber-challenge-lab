# Cyber Challenge Lab

คัดกรองข้อความหลอกลวงภาษาไทย ด้วย Claude บน Microsoft Foundry

แล็บสำหรับ Online Workshop 2 · Thailand Cyber & Digital Innovation Challenge
เสาร์ 28 พฤศจิกายน 2569 · 09.00–12.00 น. · อบรมออนไลน์ผ่าน Microsoft Teams

## เริ่มใช้งาน

1. กดปุ่ม **Code** สีเขียวด้านบน แล้วเลือกแท็บ **Codespaces**
2. กด **Create codespace on main** แล้วรอ 2–3 นาที
3. ถ้า VS Code ถามว่า *Do you trust the authors of the files in this folder?* ให้กด **Trust Folder & Continue**
4. เปิดไฟล์ `lab_scam_triage_claude_foundry.ipynb` มุมขวาบนควรขึ้น **Python 3.11** ให้อัตโนมัติ
   ถ้ายังขึ้น *Select Kernel* ให้กด **Select Kernel → Python Environments... → Python 3.11** (`/usr/local/bin/python`)
5. ทำตามทีละเซลล์

ไม่ต้องติดตั้งโปรแกรมใดลงเครื่อง ไม่ต้องตั้งค่า Python และไม่ต้องสมัครบัญชี Microsoft Azure เอง

คู่มือทำตามทีละขั้น: https://training.codediva.co/workshops/cyber-challenge
(รหัสเข้าดูแจ้งในห้องอบรม)

## English

A hands-on lab: build an AI assistant that screens **Thai** scam messages, with Claude on Microsoft Foundry.
Online Workshop 2 · Thailand Cyber & Digital Innovation Challenge · Saturday 28 November 2026

1. Click the green **Code** button, then the **Codespaces** tab
2. Click **Create codespace on main** and wait 2–3 minutes
3. If VS Code asks *Do you trust the authors of the files in this folder?*, click **Trust Folder & Continue**
4. Open **`lab_scam_triage_claude_foundry_en.ipynb`** (English edition; the Thai edition is `lab_scam_triage_claude_foundry.ipynb`).
   Top right should already show **Python 3.11**; if it says *Select Kernel*, pick
   **Select Kernel → Python Environments... → Python 3.11** (`/usr/local/bin/python`)
5. Run the cells one by one

Nothing to install, no Python setup, no Azure account of your own. Never commit your team key.
The sample messages are made up for teaching; every number, link and account in them is fake.

Step-by-step guide: https://training.codediva.co/en/workshops/cyber-challenge (password given in the session)
